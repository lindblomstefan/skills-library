# Starter Issues

Create these issues first to turn the library idea into a managed backlog.

## Foundation

### Define catalog schema

Create a minimal schema for tracking skills independent of where they live.

Expected output:

- Required fields
- Optional fields
- Status values
- Source types
- Decision outcomes

### Define evaluation rubric

Create the rubric used to evaluate external and internal skills.

Expected output:

- Scoring criteria
- Red flags
- Approval threshold
- Required reviewer roles

### Define contribution workflow

Document how someone proposes, evaluates, builds, reviews, and deprecates a skill.

Expected output:

- Contributor steps
- Reviewer steps
- Governance expectations
- Update cadence

## Discovery

### Discover external skills for planning and product discovery

Find candidate skills, methods, or templates that improve initiative planning, product discovery, roadmap slicing, requirements, and decision framing.

### Discover external skills for coding and refactoring

Find candidate skills for implementation workflows, repo onboarding, code review, refactoring, debugging, and migration work.

### Discover external skills for testing and quality

Find candidate skills for unit testing, integration testing, end-to-end testing, test strategy, regression risk, and quality gates.

### Discover external skills for UI, UX, and accessibility

Find candidate skills for frontend design, usability review, accessibility review, design-system use, and interface polish.

### Discover external skills for architecture and security

Find candidate skills for architecture decision records, API review, threat modeling, secure code review, privacy, and compliance.

## Build Candidates

### Build skill: initiative kickoff

Create a company skill that turns a fuzzy project idea into an actionable initiative brief.

### Build skill: engineering decision record

Create a company skill for writing concise decision records with options, tradeoffs, consequences, and review status.

### Build skill: pull request review

Create a company skill that reviews changes using company expectations for correctness, maintainability, tests, security, and documentation.

### Build skill: release readiness

Create a company skill that checks whether a change or initiative is ready to release.
