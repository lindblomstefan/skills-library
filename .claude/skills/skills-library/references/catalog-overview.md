# Skill Library Catalog Overview

Use this only when the full `skills-library` CLI is unavailable. Prefer the CLI when possible because it uses the current catalog manifests.

## Current Public Candidate Groups

- Repo mapping and codebase understanding: `graphify`
- GStack workflow candidates: planning, reviews, QA, release, deployment, careful operation, documentation, benchmarking, and security-office patterns from `garrytan/gstack`
- MCP and tool discovery: `awesome-mcp-servers`, `modelcontextprotocol-servers`, `playwright-mcp`
- Agent architecture and learning: `twelve-factor-agents`, `ai-agents-for-beginners`, `generative-ai-for-beginners`, `awesome-ai-agents`
- Coding agents: `continue`, `aider`, `openhands`, `swe-agent`, `devika`, `gpt-engineer`, `cline`, `roo-code`
- Frontend/prototype generation: `bolt-diy`
- Backend/API generation: `openapi-generator`
- Editor/rule catalogs: `awesome-cursorrules`, `awesome-copilot`
- Prompt/reference catalog: `prompts-chat`

## Recommendation Rules

- Treat all public entries as candidate or evaluating unless the full catalog says otherwise.
- Standard-ready recommendations require approved/in-use status and clear license state.
- Exploratory recommendations may include candidates, but blockers must be shown.
- `NOASSERTION`, unknown, needs-review, restricted, blocked, or paid license states require human review before approval.
- Reference catalogs such as `awesome-*` are discovery sources, not approval to fetch every downstream repository.

## First Questions

Ask only what is needed:

1. What is the idea, goal, and intended end product?
2. May I inspect this repo before recommending skills?
3. What outcome are you trying to achieve: onboard, plan, build, review, test, secure, document, deploy, or learn?
4. What is the repo shape: frontend, backend, full-stack, library, infrastructure, data/AI, docs, or unknown?
5. Which runtime/model should the skills work with?
6. Any privacy, license, network, or production constraints?

If answers conflict, pause recommendations and name the contradiction.
